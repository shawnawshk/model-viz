`sglang.png` is not from Lobe Icons (it has no SGLang icon). It is the 192×192
favicon of the SGLang documentation site (`docs.sglang.io`, `android-chrome-192x192.png`),
cropped to the mark and resized to 96×96, used as the icon for the SGLang cookbook link on model pages. SGLang is licensed
under Apache-2.0 ([sgl-project/sglang](https://github.com/sgl-project/sglang)).

The assets are bundled locally so provider navigation and the model-page links work offline.
